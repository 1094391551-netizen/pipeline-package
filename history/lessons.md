# Lessons — 踩坑教训与有效做法(下轮自动生效)

## 取证
- WebSearch 在美国以外常被拒答 → **默认绕过,直接 WebFetch 权威 URL**。
- 不要把 404 / 搜索结果页 / 登录页 / 平台首页当证据。GoodHousekeeping/Wirecutter/Reddit 搜索曾大量返回 404/451/首页。
- Reddit 网页常 403 → 试 `https://www.reddit.com/r/<sub>/...json` JSON 接口绕过。
- Old Farmer's Almanac longrange 页常 403、climate.gov 冬季展望页常 404 → 改用 NOAA CPC 权威源(ensodisc / long_range)。

## SIF
- **AO 随时间区间变化极大**(同 ASIN 历史 1.40,最近30天 0),每条必须写清区间。
- 季节品 AO 在旺季月(9-1月)取才有意义;淡季低 AO 失真。
- 切时间下拉会触发导航 → **导航后重填 ASIN** 再反查。
- **URL 带 `date=30` 但下拉控件不回填(仍显示"最近7天")→ 每个候选都要手动重切30天 + 重填ASIN**(2026-06-26 实证,稳定复现)。
- 校准基准 ASIN `B0DJPXJKT4` 最近30天 AO=0(全部13/自然13/广告0),可用于自检链路。
- 季节品旺季月下拉历史出现浏览器卡顿 → 跑前先确认该交互可用。
- 所有进 SIF 的候选都要点开 Business Address 核实卖家国家(曾只查 1/4)。
- 反查结果页若展开完整,会直接给出 BSR/30天销量/卖家/品牌/核心词周搜索量(比单读概览信息更全)。

## 决策
- 低 AO ≠ 低竞争:low AO + 低价 + 同质化 = 薄毛利陷阱,新人进场必死。
- **低 AO 也 ≠ 好机会**:AO 健康但大盘窄(<100 results)/销量低(<50)= 利基天花板问题。AO 之外必须同时看大盘规模 + 销量(2026-06-26:储能罩AO0.06/黑胶AO0 都健康但盘小)。
- 没 AO 只能 AO pending,不给 YES。
- **承重/承载类配件(叠放架等)= 承重关键安全红线,且常带专利([Patented]),前台标题/标识即可初筛砍掉,不必进SIF**(2026-06-26 热泵干衣机叠放套件案例)。
- 「搬迁缺口」要先确认 Amazon 是否已被填补:eBay/独立站有缺口 ≠ Amazon 缺位(黑胶铰链 Amazon 已被大量中国卖家 exact-fit 件占据)。
- 趋势强但标的差时,主动在大盘里另寻 AO 更健康、价格在线、卖家本土的替代 ASIN。
- 弱趋势线索初筛即补一条真实零售/教程实页,否则降级。

## 编排/自主运行
- 子 agent 不能再开子 agent、不能向用户提问 → 编排放主线串行,子 agent 单阶段失败即返回。
- SIF/Amazon 验证依赖单一已登录浏览器 → **阶段2 不并发**,主线串行驱动,避免抢占。
- 权限弹窗是连跑最大拦截 → 开跑前确认完全访问权限。
- 本 pipeline 需前台浏览器会话,别纯后台 cron(headless 下交互式 MCP 可能不可用)。
